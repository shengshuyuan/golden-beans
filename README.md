# 金豆

> 中文副标题：习惯养成打卡
> 英文名：Golden Bean
> 英文副标题：Habit Check-in

基于 Vue 3 + Vite 开发的习惯养成打卡应用，核心机制是通过“金豆”奖励鼓励用户持续完成日常习惯，并将积累的金豆用于兑换自定义奖励。

## 开发命令

```bash
npm install
npm run dev
npm run build
npm run preview
```

- 项目目录：`habit-tracker/`
